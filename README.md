# JSON 工具:格式化、对比、转 TypeScript

一个 Chrome 扩展(Manifest V3,v1.1.0),用于格式化、压缩、修复和对比 JSON,生成 TypeScript、Zod、JSON Schema,并解析和拼接 URL 参数。

**所有处理都在本机完成,不上传任何数据。**

## 功能

- **格式化 / 压缩 / 自动修复**:缩进可选 2 或 4 空格;出错时可跳到错误位置并自动修复;支持键排序(保持原顺序、升序、降序)、行号、自动换行、撤销、载入示例和反转义。
- **树形浏览**:展开 / 折叠(全部、保留第一层、展开到指定层级)、搜索与查询;可复制路径、JSONPath 和值;可编辑或删除字段。
- **JSON 对比**:分别输入旧 JSON 和新 JSON,并排查看新增、删除、修改和类型变化;可按类型筛选,并选择性应用补丁。
- **代码生成**:生成 TypeScript 类型、Zod 校验和 JSON Schema,可设置根类型名。
- **URL 参数**:解析和拼接 URL 参数,支持添加参数和批量导入。
- **批量替换**:可只换值、只换键名,或键名和值一起换。

> 功能清单根据 `manifest.json` 的描述和界面文案整理,尚未逐项做运行验证。

## 安装(开发者模式加载)

1. 打开 Chrome,访问 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」,选择本仓库所在文件夹。
4. 点击工具栏中的扩展图标,会在新标签页打开工具,可同时打开多个。

最低要求:Chrome 102。

## 文件结构

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置:名称、版本、图标、权限、Service Worker 入口 |
| `background.js` | 点击工具栏图标时,在新标签页打开 `app.html` |
| `app.html` | 页面壳,只含 `#root` 容器和对 `app.js` 的引用 |
| `app.js` | 构建产物,包含 React 18.3.1 及全部业务逻辑和样式(约 0.56 MB) |
| `icons/` | 16、32、48、128 像素的扩展图标 |

## 权限与隐私

只申请了 `storage` 权限。根据扩展描述,数据处理在浏览器本地完成,不上传任何数据。
